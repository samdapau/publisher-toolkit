# KDP Paperback Wrap Generator

**Turn a finished front cover into a print-ready KDP paperback full wrap — back, spine, and front — in about two seconds.**

![Guide preview generated by the tool](test-wrap-preview-chat.jpg)

*The guide preview: trim boxes, the 0.5 in text safe zone, the spine, and the barcode keep-out zone. Guides appear only in the preview file — never in the print files.*

Free. No ads. No tracking. Works offline. No account, no upload, no watermark — your cover never leaves your computer.

---

## What it does

Give it your front cover image and your book's page count. It builds the complete wrap at exactly 300 DPI, using standard KDP paperback cover-template geometry:

- **Total size** = trim × 2 + spine + 0.25 in wide, trim + 0.25 in high
- **Bleed** 0.125 in on the outer edges only — never on the spine side of a panel (the mistake that makes front covers drift off-centre in KDP's previewer)
- **Spine width** from KDP's per-page factors: white paper 0.002252 in, cream 0.002500 in, color 0.002347 in
- **Artwork is never distorted** — your cover is scaled uniformly to the trim box and the bleed is filled by edge extension, not by stretching
- **Spine text**, auto-sized and reading bottom-to-top (US convention), drawn when the spine is at least 0.35 in wide, skipped with a warning when it is thinner
- **Spine color** sampled from your front cover's spine-side edge (darkened), or set it yourself
- **Barcode zone kept clear** — KDP prints the barcode itself (2 × 1.2 in, lower spine-side corner of the back cover). The tool draws **no** fake barcode box (a drawn box only creates a misaligned double box under KDP's real one); it keeps a 2.6 × 1.8 in zone free and shows it in the preview

Outputs, from one command:

| File | What it is |
|---|---|
| `<name>-wrap.pdf` | The print file you upload to KDP (exact page size, 300 DPI) |
| `<name>-wrap.png` | The same wrap as a lossless image |
| `<name>-preview.jpg` | The wrap with guide overlays, for checking before you upload |

## Install

Python 3.9 or newer, plus Pillow — that's the only dependency:

```bash
pip install pillow
```

## Usage

```bash
python3 wrap.py --front front.jpg --pages 168 --trim 6x9 --paper white \
    --spine-text "The Thirty-Six Stratagems, Decoded · Samdapau" \
    --out my-book
```

### Options

| Option | Meaning |
|---|---|
| `--front` | Front cover image (required). Any size — it is fitted without distortion. |
| `--back` | Back cover image (optional). Fitted the same way as the front. |
| `--back-color` | Hex color for a plain back cover, e.g. `#f6f1e6` (when `--back` is not used). |
| `--back-text` | UTF-8 text file typeset onto a plain back cover: first block is the headline, blank lines separate paragraphs. |
| `--pages` | Final page count of your interior PDF (required). Use the count of the file you actually upload — spine width depends on it. |
| `--trim` | `5x8`, `5.5x8.5`, `6x9`, `6.14x9.21`, `7x10`, `8.5x11` (default `6x9`). |
| `--paper` | `white` (default), `cream`, or `color`. |
| `--spine-text` | e.g. `"My Title / Jane Author"`. |
| `--spine-color` | Hex color; overrides the sampled spine color. |
| `--out` | Output filename prefix (required). |

### Before you upload — a 30-second check

1. Open the `-preview.jpg`. Every word on the front and back should sit **inside the dashed safe zone** (0.5 in from all trim edges), and the barcode zone should be empty.
2. Make sure `--pages` matches the page count of the interior PDF you are uploading. A wrong page count means a wrong spine — this is the #1 cause of KDP cover rejections.
3. Upload the `-wrap.pdf` in KDP's cover section and confirm in KDP's own previewer.

## Notes on the geometry

The layout follows KDP's paperback cover template: each panel is composed on its trim box, bleed extends outward only, and text belongs on the trim, not on the bleed-inclusive panel. One pixel-level detail: 0.125 in at 300 DPI is 37.5 px, so the leading bleed is floored to 37 px and the trailing edge takes the extra pixel — this reproduces KDP's template dimensions exactly (a 168-page 6×9 wrap on white paper is 3788 × 2775 px).
