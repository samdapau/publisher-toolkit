# Publisher Toolkit

Free tools for indie publishers and self-published authors.

**Free for the long run. No ads. No tracking. Everything works offline.**

Every tool in this kit was built for a real publishing production line — the Samdapau classics catalogue on Amazon KDP — and used on real books before it was released here. No demos, no crippled versions: what you download is the tool we use ourselves.

## Tools

| Tool | What it does |
|---|---|
| [KDP Wrap Generator](kdp-wrap-generator/) | Builds a print-ready KDP paperback full-wrap cover (front + spine + back) from your front cover art and page count — exact spine width, bleed, and barcode clearance, with a guided preview so you can check everything before you upload. |

More tools are in production and will be added to this kit: an audio narration quality checker (gap-noise and hidden tone detection for audiobooks and podcasts) and a cover typesetting helper.

## Principles

- **Free** — building a name, not a paywall. Paid tools may come later; these stay free.
- **Simple** — one job per tool, sensible defaults, no accounts, no setup wizards.
- **Fast** — each tool runs in seconds on an ordinary laptop.
- **Private** — no analytics, no network calls, your files never leave your machine.
